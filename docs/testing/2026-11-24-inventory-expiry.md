# 库存到期日期与批次升级

目标：手机录入可选到期日期，屏幕优先显示需要关注的食材。固件路线仅 `shiyu_idf`，保留30MHz、双显示缓冲、照片单解码缓冲、原分区及配网。日期是用户填写的参考，不代表食品安全结论。

## 规则

- 名称、单位、到期日一致时新增累加；不同日期分批；未填日期之间合并。继续拒绝同名跨单位，不做单位换算。
- 编辑修改一批，撞另一批则拒绝覆盖并保留输入，不擅自合并。最多100批。
- 屏幕按食材汇总数量，优先最早填写日期，无日期最后；详情查看各批数量和日期。
- 北京时间计算已过填写日期、今天到期、三天内临近；未校时不做日期状态判断。
- 旧库存不补造日期；旧schema1缓存兼容读取。新schema2缓存写入后，旧固件不能读取该新槽，回退旧固件需联网重新同步（旧槽若还有效可读取，不保证一直保留）。照片不受影响。

## 真机门禁

- 旧日期空记录离线仍可见；升级联网后日期同步；0数量记录不自动删除。
- 一种食材两批日期不同，列表一行总量与批数、详情两批；手机删除第一批，剩余批仍正常显示。
- 过去/今天/三天内/远期/未填，顺序与文案正确；未校时只展示日期；跨北京时间午夜状态刷新。
- 超六种翻页、详情返回保留页码、长名称及8字单位、100批详情滚动可达。
- 轮播直接输入30、保存及重进；空值/4/301拒绝，5/300边界；确认键和退格可触摸。
- 首页/设置/照片无黑线与微抖动；观察运行内存与Wi-Fi/照片并发，不以编译成功替代。
