# 屏幕阶段界面 V1

目标路线：`firmware/shiyu_idf`。本轮唯一结果是落地阶段界面，等待烧录后看效果；菜品管理和推荐尚未设计，首页不是最终信息架构。

## 实施范围

- 首页：真实库存前四条、总数、同步状态、网络校时后的北京时间和日期、设置入口。移除可见菜谱 DEMO 和未开启临期占位。
- 库存：单列六行、食材名称左对齐、数量单位右对齐、固定分页；首尾按钮禁用；详情返回保留页码。
- 详情：名称、数量和单位、同步状态及手机编辑提示；屏幕只读。
- 设置：网络配置、照片轮播间隔入口、设备绑定状态入口。实际配网键盘和云端绑定流程保持。
- 照片：移除常驻“环境模式”标题，维持触摸返回和原轮播行为。

中文沿用统一24px动态字库，品牌沿用28px标题字库；新增Montserrat48用于时钟。为控制资源，详情中文未照搬网页稿的大字号。轮播设置及绑定二级页保留原操作流程，本轮不重做其全部视觉。原型截图不代表真机效果。
