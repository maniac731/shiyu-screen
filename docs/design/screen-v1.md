# 屏幕视觉提案 01

日期：2026-11-24。目标：为1024×600横向七英寸触摸屏提供可评审的页面效果与交互，不修改固件、不构建、不烧录、不部署。

[可点击原型](screen-v1.html)使用独立示例数据，不连接云端。上方页面和状态切换器是评审工具，不属于硬件界面。照片背景为SVG抽象占位。浏览器预览按本机中文字体回退；最终以固件字库覆盖、体积和真机显示验收为准，不宣称网页截图等于真机截图。

## 本轮设计取舍

- 只呈现已具备的真实库存、照片、时间和设置。首页移除菜谱DEMO及未启用的临期卡，不为尚未实现的能力占据主要位置。
- 库存仍只有名称、数量、单位；不在视觉稿中暗加分类、位置、到期、推荐或批次字段。
- 手机负责录入及修改，屏幕负责轻量查看；不增加加减库存、吃完、删除等写操作。
- 默认约60秒无操作进入照片轮播；照片无常驻导航和“环境模式”字样，轻触回首页。原型为便于评审不自动跳页。

## 页面分布

| 页面 | 内容与层级 | 操作 |
| --- | --- | --- |
| 首页 | 左侧库存预览与真实总数；右上大时间/日期；右下简短手机管理说明；顶部小同步状态 | 查看全部进入库存；右上设置是唯一设置入口 |
| 库存 | 单列六行，名称左、数量和单位右；不为每种食材添加无数据来源的插画；整行可点 | 左上返回首页；底部固定上一页/页码/下一页，首尾禁用；点击进入详情 |
| 食材详情 | 放大名称与数量，保留单位；小字说明手机更新 | 左上回库存，保留此前页码；不设置假编辑按钮 |
| 照片 | 照片满屏覆盖；不显示设置、固定底栏或原型占位文字 | 轻触回首页；维持现有轮播间隔设置 |
| 设置 | 网络状态与配置入口、轮播秒数与保存、所属厨房信息 | 左上回首页；网络选网/密码页复用已验收流程，原型仅标出入口；成员管理留在手机 |

首页只预览前四条，不将它们标为“常用”或“最近”，因为当前没有对应数据规则。库存名很长时列表单行省略，详情允许换行；数量不省略、不自动换单位，去掉无意义的小数尾零。0数量记录显示0，不擅自删除或推断不存在。

## 状态

- 已同步：小绿色点与文字，不用颜色作为唯一信息。
- 离线：明确“离线 · 显示上次库存”，保留缓存；详情提醒数量可能变化。上次同步时间由真实元数据提供，不写死。
- 首次同步：总数用“—”，不把未知库存当成0；时间无效时显示“--:--”，不伪造日期。
- 空库存：只有取得有效空快照后才展示“厨房还空着”，提示在手机添加。

## 视觉与触摸

- 暖米白背景、深绿正文、浅绿功能块；离线用低饱和暖棕。无玻璃模糊、重阴影、大面积滑动转场。
- 原生画布1024×600；四周主要安全边距36px；顶部统一返回箭头与横排标题；设置只在首页。
- 正文约24px，页面标题28px，动态名称约27–40px、数量更突出。统一中文无衬线字形与字重体系，不拼接大小不同的缺字补丁。大字号中文需要实施前核对字库覆盖及APP体积；不能仅为了照搬网页字号扩大分区或侵占已确认照片资源。
- 返回/设置触摸区域60×60px，库存行66px高，操作按钮至少56px高，相邻触摸点间距>=8px。数量/单位明确区分字号。
- 页面点击有短暂按压反馈；保持返回位置稳定。六行是提案，若真机可读性/响应不满足则回退四行，不靠缩小字号硬塞内容。

## 实施边界与回退

保留已验收30MHz、双显示framebuffer、单照片资源复用及现有轮播/缓存/设备授权。视觉变更不得暗改显示参数、增加全屏缓存、自动生成食材图片或引入长按。网络选网及密码键盘布局本轮不重做。

实施建议顺序：先首页/库存/详情，再统一设置中文与状态，最后收掉照片页常驻演示文字。每步保留当前可回退固件。当前仅新增设计文件，不把原型完成标为implemented/compiled/flashed/device-tested。

## 预览检查

检查原生1024×600布局、库存翻页、详情返回原页、轮播设置保存模拟、离线/空库存/首次同步状态。真实触摸、中文缺字、显示稳定性与资源峰值需实际实施后验收。本稿不能替代这些门禁。

已完成浏览器检查：五页主画布均为1024×600，主要控件无越界；库存翻页与详情返回原页通过；轮播9秒保存模拟通过；离线保留示例库存、空库存显示0、首次同步显示未知计数与--:--通过。主要正文/背景组合对比度实算4.68–10.46。以上仅原型检查，不属于固件真机验收。
