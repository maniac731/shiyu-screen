# 手机登录与邀请实施

本轮网页入口位于 `web/`，采用 Vite、vanilla TypeScript、官方 Supabase JS SDK。账号身份使用邮箱 OTP，正常保留登录；登录后读取本厨房及成员，未归属账号可创建厨房。

邀请从手机创建者生成，通过 fragment URL 分享。接收者登录后调用 `preview_invitation`，主动确认后调用 `redeem_invitation`。已有厨房账号不可切换加入；邀请不自动消费。创建者可以确认后移除普通成员；转让、主动退出厨房、设备解绑不在本轮实现。

运行与 Supabase 邮件配置统一见 `web/README.md`。目前只有客户端代码和本地检查，未操作云端、未填写真实 key，不能宣称真实邮箱登录或数据库权限已经通过。数据库迁移及测试状态仍以对应契约记录为准。
