# 食愈屏幕：手机无线传图 MVP

## 验收目标

- 手机连接屏幕发出的 Wi-Fi。
- 手机浏览器选择任意照片，自动裁成 1024 × 600 后发送。
- 屏幕全屏显示照片。
- 断电重启后仍显示最后一次成功上传的照片。

## Arduino IDE 设置

- 开发板：`ESP32S3 Dev Module`
- Arduino ESP32：`3.3.12`
- Flash Size：`16MB (128Mb)`
- Partition Scheme：`16M Flash (3MB APP/9.9MB FATFS)`
- PSRAM：`OPI PSRAM`
- Upload Mode：`UART0 / Hardware CDC`（使用板上标注 `UART1` 的下载口时沿用此前成功的上传设置）

分区方案必须选 FATFS 这一项，否则图片无法断电保存。

## 使用

1. 编译并上传 `wireless_photo_display.ino`。
2. 屏幕启动后，手机连接 Wi-Fi：`ShiYu-Screen-A02`。
3. 密码：`shiyu2026`。
4. 手机浏览器打开 `http://192.168.4.1`。
5. 选择照片，确认预览后点“发送到屏幕”。

手机可能提示“此网络无法连接互联网”，这是正常现象，请选择继续使用该网络。

## 当前边界

- 仅保存并展示最后一张照片。
- 图片采用“裁满屏幕”，不会拉伸变形，但边缘可能被裁掉。
- 当前为本地直连 MVP，不需要路由器和云服务。
- 修改分区方案并烧录可能清空此前保存的图片，但不会影响已经备份的原厂固件。

## 已记录的下一轮优化

- 现象：传输图片过程中，屏幕会出现短暂抖动或旧画面异常刷新。
- 目标体验：上传开始后立即插入黑色遮罩，并在屏幕上显示真实传输进度；上传和校验完成后，再一次性切换到新图片。
- 验收标准：传输期间不暴露半帧图片、旧画面或抖动画面；失败时显示失败提示并保留上一张有效图片。
